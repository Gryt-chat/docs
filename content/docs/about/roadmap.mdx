## Direct messages and social

- ✅ Direct messages (1:1, per server)
- ✅ Group direct messages, and calls in them
- ✅ A Messages space with every conversation from every server in one list, and pins
- ✅ Friends (requests, accept, decline, remove)
- ✅ Blocking, which also stops their messages and calls
- ✅ Who can message and call you, as a default and per server
- ✅ End-to-end encrypted direct messages, using MLS so a key that leaks later can't open older messages
- ✅ Link a new device from one you already use, by QR code or a short code
- ✅ Named devices, with old ones removed in one click
- 📋 End-to-end encrypted private channels

A direct message belongs to the server you opened it on. Messaging the same
person on another server starts a separate conversation with its own history,
and neither server can tell the two are the same people. That is deliberate:
carrying a conversation between servers would mean either storing everyone's
private messages centrally or letting servers tell each other which servers you
are on. Your messages sit on that server, so whoever runs it can read them, the
same as any channel. Server owners can turn direct messages off entirely.
